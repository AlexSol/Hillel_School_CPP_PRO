# clang-format

`clang-format` - це інструмент для автоматичного форматування коду C, C++ та інших мов у стилі, який задається через файл `.clang-format`.

У цій папці є маленький приклад, який показує:
- як виглядає неформатований код;
- як `clang-format` перебудовує відступи, переноси та пробіли;
- як швидко перевірити або застосувати форматування через `Makefile`.

## Файли

- `.clang-format` - правила форматування;
- `example.cpp` - демонстраційний файл;
- `Makefile` - швидкі команди для показу і застосування форматування.

## Швидкий запуск

Показати, як `clang-format` відформатує файл:

```bash
make show
```

Перевірити, чи файл вже відформатований:

```bash
make check
```

Застосувати форматування до файлу:

```bash
make format
```

Повернути демонстраційний файл у навмисно "погано" відформатований стан:

```bash
make reset
```
