# clang-tidy

`clang-tidy` - це інструмент статичного аналізу для C++, який допомагає знаходити проблемні місця у коді та часто може автоматично виправляти частину з них.

У цій папці є маленький приклад, який показує:
- як `clang-tidy` знаходить типові зауваження у коді;
- як застосувати автоматичні виправлення;
- як швидко запускати перевірку через `Makefile`.

## Файли

- `.clang-tidy` - набір правил перевірки;
- `example.cpp` - демонстраційний файл із навмисними зауваженнями;
- `Makefile` - швидкі команди для перевірки та auto-fix.

## Швидкий запуск

Показати зауваження:

```bash
make show
```

Перевірити файл і завершитися з помилкою, якщо є зауваження:

```bash
make check
```

Застосувати автоматичні виправлення:

```bash
make fix
```

Повернути приклад у початковий демонстраційний стан:

```bash
make reset
```
